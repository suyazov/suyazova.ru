# Копия файлов сайта suyazova.ru от 14.11.2026

Сохранено 65 файлов, 5 971 835 байт до сжатия. В архиве опубликованная статическая сборка. Контрольные суммы частей и файлов приложены.

## Проверка и восстановление

1. Склонируйте репозиторий и перейдите в `recovery/snapshot-20261114`.
2. Выполните `sha256sum -c PARTS.sha256`. В пустой временный каталог соберите и распакуйте архив командой `cat files.tar.gz.part-* | tar -xzf - -C /путь/к/временному-каталогу`.
3. Перейдите в распакованный каталог и выполните `sha256sum -c SHA256SUMS`, указав полный путь к манифесту из репозитория.
4. Разместите проверенные файлы в корне сайта. Для форм и правил маршрутизации используйте инструкцию «Сервер».

Настройки сервера, доступы и служебное состояние форм восстанавливаются по [инструкции «Сервер»](https://github.com/suyazov/affine-pages-backup/blob/main/affine/infrastructure/Сервер.md).
